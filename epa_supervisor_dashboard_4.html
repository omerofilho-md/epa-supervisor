Como configurar — 3 passos

Passo 1 — Abrir o Script Editor

No Google Sheets da planilha PRMCG_EPA_Sheets: menu Extensões → Apps Script

Passo 2 — Colar o script

Apague o conteúdo existente no editor e cole o script abaixo.

Use o botão verde acima para copiar. Não selecione o texto manualmente — pode copiar formatação incorreta.

Passo 3 — Publicar como Web App

No Script Editor: Implantar → Nova implantação → Tipo: App da Web

Executar como: Eu  |  Quem pode acessar: Qualquer pessoa

Clique em Implantar, autorize e copie a URL gerada.

Cole a URL no campo acima e clique em Testar conexão.
